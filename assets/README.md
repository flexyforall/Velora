# Ассеты лендинга Wedge

Источник: Figma «Wedge-Internal», фрейм **Home** (`904:5033`), 1440 × 8017.

В каждой папке лежит `README.md` со списком файлов, которые туда нужно загрузить.
Имена файлов должны совпадать **в точности** — вёрстка ссылается на них по имени.

## Правила экспорта

- **Векторы** (иконки, логотипы из кривых) — `SVG`, масштаб 1x, без обрезки по контенту (размер фрейма как в Figma).
- **Растровые логотипы и картинки** — `PNG` @2x (размер в таблицах указан в 1x, т. е. как на макете).
- **Фотографии** (фоны) — `JPG` @2x, качество 80–85 %.
- Линии-разделители, градиенты, точки-маркеры и тени делаются в CSS — их загружать не нужно.
