Секция `Hero` (`521:1529`), 1440 × 810.

## Фоновое видео — загрузить сюда

| Файл | Обязательно | Что это |
| --- | --- | --- |
| `hero-bg.mp4` | да | Видео на фон первого экрана, H.264 |
| `hero-bg.webm` | нет | Та же запись в VP9/AV1 — весит меньше, браузер выберет сам |

Требования к видео:

- **Размер кадра:** 1920 × 1080 или 2880 × 1620 (16:9). Видео заполняет всю область 1440 × 810 и обрезается по краям, как картинка на макете.
- **Без звука** — браузеры запускают автоматически только беззвучные ролики.
- **Зацикленное**, 10–20 секунд, чтобы стык конца и начала был незаметен.
- **Вес:** до 10–15 МБ. Через веб-интерфейс GitHub можно загрузить файл до 25 МБ; больше — только через `git push` (лимит 100 МБ).
- Затемнять видео не нужно: поверх него в CSS идёт градиент из макета (сверху прозрачный → снизу чёрный 40 %, три слоя).

`hero-bg.png` остаётся постером: он показывается, пока видео грузится, и на устройствах, где автозапуск запрещён.
