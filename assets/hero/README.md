# hero/ — первый экран и видео по скроллу

Первый экран закреплён, пока пользователь прокручивает страницу: скролл проматывает видео кадр за кадром
(здание → офис → экран), а последний кадр — это ровно секция Agents, которая затем плавно её подменяет.
Текст первого экрана исчезает за первые 10 % прокрутки, последние 8 % видео стоит на финальном кадре.

| Файл | Что это |
| --- | --- |
| `wedge-full-2880x1620.mp4` | Исходник (25 МБ, со звуком). Сайт его не грузит, хранится как оригинал |
| `hero-scrub.mp4` | Версия для сайта: H.264, 2880×1620, без звука, ключевой кадр каждые 6 кадров (10 МБ) |
| `hero-poster.jpg` | Первый кадр видео — виден, пока видео загружается |
| `hero-bg.png` | Картинка из макета Figma — показывается, если в системе включено «уменьшение движения» |
| `btn-icon.svg` | Иконка в кнопке «Book a Demo» |

## Как заменить видео

Последний кадр нового ролика должен совпадать с секцией Agents при ширине 1440 px (кадр 16:9).
Из нового исходника нужно заново собрать `hero-scrub.mp4` и `hero-poster.jpg`:

```sh
ffmpeg -i new-video.mp4 -an -vf "scale=2880:-2:flags=lanczos" -c:v libx264 -preset slow -crf 23 \
  -g 6 -keyint_min 6 -sc_threshold 0 -bf 0 -pix_fmt yuv420p -movflags +faststart hero-scrub.mp4
ffmpeg -i new-video.mp4 -frames:v 1 -q:v 3 hero-poster.jpg
```

Частые ключевые кадры (`-g 6`) обязательны: без них прокрутка назад и быстрые рывки скролла будут подтормаживать.
