# footer/ — футер с большим логотипом Wedge

Секция `Footer` (`904:5181`), 1440 × 599. Логотипы в нижней полосе берутся из `../partners/`.

| Файл | Размер (1x) | Слой в Figma | Где на макете |
| --- | --- | --- | --- |
| `pattern.png` | 1440 × 733 | `Union 1` (`904:5182`) | Точечный фон футера (на макете прозрачность 20 % — задаётся в CSS) |
| `wordmark.png` | 1211 × 315 | фрейм `telegram-cloud-photo-size-2-…-y 5 [Vectorized]` (`904:5197`) | Большой «расколотый» логотип Wedge |

**Важно про `wordmark.png`:** на логотип в Figma наложен шейдер-эффект «Pattern refraction».
В браузере он работает только через WebGPU, поэтому экспортируйте **весь фрейм** `904:5197` в PNG @2x,
чтобы эффект «запёкся» в картинку. Прозрачность 50 % экспортировать не нужно — она задаётся в CSS.
