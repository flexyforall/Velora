# Velora

Лендинг Velora по макету из Figma: [Velora → Animation](https://www.figma.com/design/1Ebb2p67jrZHNAmbTDkn0O/Velora?node-id=553-1955).
Чистые HTML/CSS/JS, без сборки и зависимостей.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Страницу нужно открывать через сервер, а не как файл: знак в лоадере подгружается через `fetch`.

После правок в `css/styles.css` или `js/main.js` поменяйте номер версии `?v=` в ссылках на них в `index.html`, иначе браузеры могут показать старую версию из кэша.

## Структура

```
index.html          разметка
css/styles.css      стили (все значения взяты из Figma)
js/main.js          лоадер, анимация по скроллу, вкладки продуктов
assets/
  fonts/            Manrope (variable 200–800), Inter Light 300 — latin, woff2
  images/           фон с лучами, логотип, подложки, график, знак лоадера
  icons/            SVG-иконки: меню, кнопки, теги продуктов, статистика
  logos/            логотипы партнёров для блока «Trusted by»
```

Новые картинки кладите в `assets/images`, иконки в `assets/icons`, логотипы партнёров в `assets/logos`.

## Анимация

Кадры из Figma и что им соответствует на сайте:

| Кадр Figma | На сайте |
| --- | --- |
| `loader` (37% / 97%) | Лоадер: кольцо прогресса, проценты, слова и штрихи знака загораются по мере загрузки |
| `home-1` | Первый экран после лоадера |
| `home-2` | После ~900px скролла: заголовок уезжает вверх, блок продукта раскрывается в дашборд, теги выстраиваются в ряд вкладок |
| `home-3` | Ещё 160px: дашборд поднимается на 63.5px, затем страница скроллится обычно — «Trusted by» и «Proven at scale» |
| `home-4` | Блок «Proven at scale» целиком |

Промежуточные состояния интерполируются между кадрами (`--p`, `--q` в `css/styles.css`).
Расстояния скролла задаются в `js/main.js` (`TRACK_MORPH`, `TRACK_SETTLE`).

Вкладки под дашбордом переключаются сами каждые 6 секунд (полоска над активной показывает прогресс) и по клику.
Логотипы партнёров при наведении становятся яркими и показывают подсказку из атрибута `data-since` в `index.html`.

## Адаптив

Макет рассчитан на 1440px. На экранах уже первый экран масштабируется целиком, шире — фон растягивается до краёв.
Мобильной версии в макете нет.
