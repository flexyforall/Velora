# Velora

Лендинг Velora по макету из Figma: [Velora → Animation](https://www.figma.com/design/1Ebb2p67jrZHNAmbTDkn0O/Velora?node-id=553-1955).
Чистые HTML/CSS/JS, без сборки и зависимостей.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Страницу нужно открывать через сервер, а не как файл: знак в лоадере подгружается через `fetch`.

После правок в `css/styles.css` или `js/main.js` поменяйте номер версии `?v=` в ссылках на них в `index.html`, иначе браузеры могут показать старую версию из кэша.

## Структура

```
index.html          разметка
css/styles.css      стили (все значения взяты из Figma)
js/main.js          лоадер, анимация по скроллу, вкладки продуктов
assets/
  fonts/            Manrope (variable), Inter 3.19 ExtraLight 200 / Light 300, Newsreader Italic (variable) — latin, woff2
  images/           фон с лучами, логотип, график, знак лоадера, луч тёмной панели
  icons/            SVG-иконки: меню, кнопки, продукты, «язычок» переключателя
  logos/            логотипы партнёров для блока «Trusted by»
```

Новые картинки кладите в `assets/images`, иконки в `assets/icons`, логотипы партнёров в `assets/logos`.

## Анимация

Кадры из Figma и что им соответствует на сайте:

| Кадр Figma | На сайте |
| --- | --- |
| `loader` (37% / 97%) | Лоадер: кольцо прогресса, проценты, слова и штрихи знака загораются по очереди |
| `home-1` | Первый экран: заголовок, кнопки, начало дашборда, пять иконок продуктов вокруг |
| `home-2` | После ~900px скролла: заголовок уезжает вверх, блок раскрывается в дашборд, иконки слетаются в переключатель продуктов над ним |
| `home-3`, `home-4` | Дальше страница скроллится обычно: «Trusted by» и тёмный блок «Proven at scale» |

Промежуточные состояния интерполируются между кадрами (`--p` в `css/styles.css`, полёт иконок — в `js/main.js`).
Расстояние скролла задаётся в `js/main.js` (`TRACK_MORPH`, `TRACK_HOLD`).

Активный продукт в переключателе меняется сам каждые 6 секунд (пауза, пока курсор над переключателем) и по клику.
Правая колонка дашборда заполняется, когда он раскрылся полностью.
Логотипы партнёров при наведении становятся яркими и показывают подсказку из атрибута `data-since` в `index.html`.

## Адаптив

Макет рассчитан на 1440px. На экранах уже первый экран масштабируется целиком, шире — фон растягивается до краёв.
Мобильной версии в макете нет.
